# Circuit Sword workflow

- Commit completed, verified changes as work progresses; do not leave finished
  work only in the conversation or on the handheld.
- Preserve changes made directly on the handheld as reproducible repository
  changes or patches, with validation results and rollback instructions.
- Push completed commits to the fork's working branch so there is a remote copy.
- Keep passwords, ROMs, personal configuration dumps and SD images out of Git.
